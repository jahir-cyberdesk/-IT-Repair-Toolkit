# IT Repair Toolkit

A free, menu-driven Windows repair and diagnostics toolkit built for IT administrators and sysadmins. One script, 20 tools — no more retyping the same commands every time.

Built and maintained by [Jahir Hussain](https://www.linkedin.com/in/jahir-hussain-599906203) — Senior System Administrator, 15+ years in IT infrastructure.

## What's inside

- System Info, SFC Scan, SFC Verify Only
- DISM Scan Health & DISM Repair (RestoreHealth)
- Component Store Cleanup
- Drive Health (SMART)
- Flush DNS & Reset Winsock
- Reset TCP/IP
- Battery Report & Performance Report
- WinRE Info & Advanced Startup
- System Restore & Memory Diagnostic
- Check Windows Update
- Full Report (All Info)
- Disk Cleanup
- Event Log Errors (Last 20)

## How to use

1. Download `IT-Toolkit.bat`
2. Right-click → **Run as administrator**
3. Choose an option from the menu (1–20)
4. All actions are automatically logged to a `Logs` folder next to the script

Please test this in a **non-production/test environment first**. No responsibility is taken for any issues that occur if this is run directly on a live production system.
